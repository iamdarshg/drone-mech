# Fresh three-correction transonic PIMPLE runs

These native OpenFOAM 1912 runs start from the original t=0 fields on the original 34,166-cell outboard-sector mesh. Compared with the first bounded transonic PIMPLE experiment, the PIMPLE dictionary has exactly one `nNonOrthogonalCorrectors 3` entry (verified in `effective_nNonOrth_ias700.txt` and `effective_nNonOrth_ias900.txt`); PIMPLE also enables `transonic yes`, pressure uses PBiCGStab/DILU, and the laplacian uses limited corrected coefficient 0.33. The source mesh and boundary fields were not modified.

Both cases passed native dry-run and advanced under 600 s wall caps before ending in exit 136 from a floating-point exception in `hePsiThermo::calculate`. IAS700 reached about 1.2109e-4 s; IAS900 reached about 1.0930e-4 s. Neither reached its 0.004 s end time or emitted a normal `End` marker. The run logs and exits are retained here; field checkpoints and offline histories are included for the persisted output times only.

These runs are fresh-start evidence, unlike `experiments/pimple_transonic_10min_clean/`, which resumes from checkpoints generated by the earlier duplicate-entry case whose effective corrector count was one. Do not treat either as a converged result, independent mesh/time-step study, or isolated proof that one dictionary change caused the behavior.
