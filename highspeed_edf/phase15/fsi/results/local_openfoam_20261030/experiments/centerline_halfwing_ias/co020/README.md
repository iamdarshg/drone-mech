# Reduced-Courant sensitivity on the experimental centerline mesh

This bounded sensitivity test uses the generated 49,208-cell experimental centerline half-wing mesh, fresh t=0 fields, transonic PIMPLE, PBiCGStab/DILU pressure, upwind transport, limited corrected laplacian, and three non-orthogonal corrections. Relative to the paired centerline experiment, the intended changes are `maxCo 0.2`, `deltaT 5e-6`, and `maxDeltaT 1e-5`. Mesh and geometry hashes are recorded in each case manifest.

Both speeds ran in two bounded segments: a fresh-from-zero segment capped at 300 s, followed by continuation from the latest complete checkpoint with a 600 s cap. Each continuation ended on its wall-clock cap with exit code 124; neither log contains a normal `End` marker. The final printed `Time =` is the start of an incomplete solver iteration, so it is not a completed timestep. The latest persisted checkpoints are IAS700 at 1.5442106e-4 s and IAS900 at 1.2588395e-4 s. The last logged attempted times were 1.5721079e-4 s and 1.3398241e-4 s, respectively. Exact logs, exit receipts, controls, and checkpoint histories are retained in this directory.

Checkpoint analysis was refreshed after the continuation. IAS700 at its latest persisted state reached T=179.1–1151.7 K and speed extrema are in `cases/checkpoint_history_ias700.json`; IAS900 reached T=173.8–728.4 K. These extreme thermal states indicate a developing nonphysical solution despite the reduced time-step cap. The runs tested sensitivity to maxCo only; neither converged and neither supports steady-load or design claims. Pressure loads are transient, omit viscous stress, and include the artificial inboard cut. The mesh lacks fuselage, root fillet, and EDF flow.
