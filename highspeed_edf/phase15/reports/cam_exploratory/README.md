# Phase 15 Sheet A FreeCAD CAM exploration

FreeCAD 1.0.0's native Path workbench generated an exploratory profile operation on one rotor blank imported from the real `sheet_A_250x120x5_36rotors_63stators.step` stock nest. The `.FCStd` preserves the STEP nest, a 250 × 120 × 5 mm stock object, the native Path Job, and a native ToolBit linked to the profile operation. The saved ToolBit is now verified as 2 mm diameter, two flutes, carbide, with an approximate 8 mm cutting edge and corresponding 2 × 2 × 8 mm flute-only shape envelope. `tool_verification.json` records the values reopened from the saved FCStd. `path_commands.txt` is the literal generated Path command list; it is not postprocessed controller code.

The tool model ends at the estimated flute envelope. Shank diameter, usable reach, stickout, and overall tool length remain unmeasured and are explicitly left out of the tool shape; the FreeCAD shank diameter parameter is set to zero only to suppress shank geometry, not to claim a physical value. The FreeCAD 8 mm length parameter applies only to the flute-only proxy and does not represent overall length or reach. Feed, spindle speed, helix, center-cutting status, runout, and the cutter maker's limits remain unspecified.

The requested stock is 6 mm thick while the existing STEP nest and stock object are 5 mm. The original geometry and stock thickness remain unchanged in this evidence. This operation is a geometry preview against that existing 5 mm file, so it does not resolve the 1 mm discrepancy. One rotor only was profiled; the remaining 35 rotors and 63 stators were not operated on.

FreeCAD reports a default 2 mm stepdown and generates cutting levels at Z = 3, 1, and 0 mm. These are software values for preview only. The tool identity uses the user's two-flute carbide specification and an approximate 8 mm flute length at the lower end of the stated 8–10 mm estimate. No feeds, spindle speed, tool engagement limit, 3018 controller/postprocessor, travel, workholding, tabs, or cut retention have been established. No material was cut and no machine was connected. Do not use this as a fabrication plan.

To reproduce, first generate the Phase 15 geometry artifacts using `phase15/optimization/phase15_generate_geometry.py`, then run `QT_QPA_PLATFORM=offscreen freecadcmd phase15/reports/cam_exploratory/make_sheet_a_cam_preview.FCMacro` from the repository root. The generated geometry artifacts are build outputs and are not committed; the macro checks for the expected source file and rotor count.
