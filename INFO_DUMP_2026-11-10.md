# INFO-DUMP — drone-mech state at 2026-11-10

Temporary context snapshot. Not a release. No geometry here is promoted.

## 1. Purpose and role in the program

`drone-mech` is the transonic EDF aircraft program: geometry, external aerodynamics,
structures, and aeroelasticity. The objective is a **promoted, buildable** aircraft with
executed CFD/FEA/FSI evidence. Nothing in this repo currently meets that bar.

The governing rules are in `highspeed_edf/AGENTS.md`. Read them before touching
flight-critical geometry.

## 3. Segments / design facts

- 72 mm motor cans overlap adjacent rotor stations by **36 mm** at 36 mm pitch.
- Four vector vanes + two elevons + one rudder = **7 actuator channels**; the flight-board
  contract is **6**. F-05 allocation remains unresolved.
- 200 mm battery bay constrains nose, inlet, and payload volume.
- Phase-15 assembly is therefore **not buildable as-is** and must not be presented as the
  aircraft.

## 4. What has been tried (and failed)

### 4.1 Geometry / mesh
- Gmsh imported 516 solids from the pinned assembly. OCC bounds were inflated by B-spline
  control geometry; triangulated bounds are ~520 × 148 × 705.5 mm. This is an import
  check, not a CFD mesh.
- OpenFOAM 2406 `checkMesh` on the synthetic outboard wing found **73 small-determinant
  cells**. HXT remesh found **302** small-determinant cells + **7 low-weight faces**;
  relocation found **263** + **3**. All fail the strict gate.

### 4.2 Transonic external flow
- Case: rigid, simplified half-wing (no fuselage, no EDF/duct, no moving rotor regions,
  no inboard production geometry, no root fillet).
- Mesh: 49,208 cells; maximum non-orthogonality **83.46°**; skewness **2.77**;
  **411** cells below the determinant threshold; **14** faces below the
  interpolation-weight threshold.
- IAS700 and IAS900 `rhoPimpleFoam` attempts **exited with floating-point exceptions**
  before completion and showed nonphysical temperature/speed growth.
- A later bounded IAS900 run (TAS 283.172 m/s, Mach 0.861815, +0.5°, maxCo 0.1) passed
  `-dry-run` but failed strict mesh checks; it was stopped at **t = 5.6100292e-6 s** when
  a local total-temperature proxy reached **353.6 K** against an approximately **309 K**
  freestream total-temperature bound. There was no normal completion.
- **Conclusion:** no shock, drag-rise, CL/CD, or flight claim exists.

### 4.3 Structures
- CalculiX 2.21 completed **10 modes** and **2 static diagnostics** on the synthetic wing
  sector, fixed at the root, with homogeneous **E = 10 GPa, ν = 0.3, ρ = 150 kg/m³**.
- The 900 IAS 1q sensitivity applies uniform upward suction on selected synthetic upper
  wing faces — not a CFD-derived load. Root reactions balance on unconstrained nodes.
- No failure criterion, laminate definition, full-aircraft coupling, or safety conclusion.

### 4.4 Aeroelastic
- The preCICE integration is a **toy field exchange**, i.e. an adapter test. It is not
  aircraft FSI evidence: no real coupling convergence, no interface mapping proof, no
  flutter margin.

| DM-G1 | Buildable geometry: 36 mm motor overlap resolved or explicitly labeled unbuildable study article; interfaces closed; STEP hash recorded |

| DM-G7 | Aircraft closure: CG/mass with every part+payload; 7 actuators vs 6 PWM resolved; power/thermal/rotor-speed containment |
| DM-G8 | Provenance: input hashes, solver versions, native logs, resource accounting, honest fidelity label |
| DM-G9 | Promotion only when every applicable gate passes; keep F-05 and motor-overlap gates visible |

## 7. Next actions

1. Freeze one buildable, mass-consistent geometry or explicitly declare the current
   assembly an unbuildable aerodynamic study article.
2. Resolve the 36 mm motor overlap and the 7-vs-6 actuator allocation.
3. Build a mesh that passes `checkMesh -allTopology -allGeometry` and the project's
   stricter determinant/interpolation gates before any long run.
4. Run a short solver smoke case, inspect field bounds and conservation, then the
   700/800/900 IAS campaign with Mach bracketing.
5. Only then run structural and aeroelastic loads from accepted pressures.

Do not report a CFD/FEA result as promoted until the corresponding gate passes with
native logs and hashes.
